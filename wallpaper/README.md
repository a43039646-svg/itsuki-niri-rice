The repository contains `itsuki-debian-niri-rice.jpg`, the compressed 1600x900 Itsuki-themed background used by Niri and LightDM.

The main installer copies it to `~/Pictures/Wallpapers/itsuki.jpg`. For Niri, it sets swaybg to that path. The optional `install-lightdm.sh` copies it to `/usr/share/backgrounds/itsuki-debian-niri-rice.jpg`.

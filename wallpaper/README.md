# Desktop wallpapers

The main installer selects the wallpaper matching the chosen variant and installs it as `~/Pictures/Wallpapers/itsuki.png`.

| File | Intended variant | Description |
|---|---|---|
| `itsuki_debian_wallpaper_v2_1600x900.png` | Debian | Original red/pink Debian spiral artwork |
| `itsuki-arch.png` | Arch Linux | Blue/cyan space background with Arch logo, no anime character |
| `itsuki-gentoo.png` | Gentoo | Violet space background with Gentoo logo, no anime character |
| `itsuki-neutral.png` | Neutral | Red/pink atmospheric background without a distro logo or anime character |
| `debian-rice.jpg` | LightDM | Dark Debian-logo background for the login greeter |

The Arch, Gentoo, and Neutral files above are the wallpapers selected by the main installer's theme menu. The LightDM background is separate from the desktop wallpapers and is used only by the optional `install-lightdm.sh` script.

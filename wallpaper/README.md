# Desktop wallpapers

The main installer selects the matching wallpaper and installs it as `~/Pictures/Wallpapers/itsuki.png`.

| File | Profile | Description |
|---|---|---|
| `itsuki-arch.png` | Arch Linux | Blue/cyan background and Arch logo, without Itsuki |
| `itsuki-arch2.png` | Arch Linux | Blue/cyan background, Arch logo, with Itsuki |
| `itsuki-gentoo.png` | Gentoo | Violet background and Gentoo logo, without Itsuki |
| `itsuki-gentoo2.png` | Gentoo | Violet background, Gentoo logo, with Itsuki |
| `itsuki-neutral.png` | Neutral | Red/pink background, no distro logo, without Itsuki |
| `itsuki-neutral2.png` | Neutral | Red/pink background, no distro logo, with Itsuki |
| `itsuki_debian_wallpaper_v2_1600x900.png` | Debian | Original red/pink Debian artwork with Itsuki |
| `debian-rice.jpg` | LightDM | Dark Debian-logo background for the login greeter |

The filename convention for Arch, Gentoo, and Neutral is intentional: a trailing `2` marks the version with Itsuki, and the version without `2` is character-free. Since no separate Debian-specific character-free wallpaper is present, choosing the clean style for the Debian profile uses `itsuki-neutral.png`.

The LightDM background is separate from the desktop wallpaper and is used only by the optional `install-lightdm.sh` script.
